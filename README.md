## 1. الترويسة ونبذة عن المنصة

**NexusUI** هي منصة تصميم متطورة ومعرض معماري شامل لمكونات الويب التفاعلية (Interactive UI Components)، تجمع بين أكثر من **400 عنصر حديث** تشمل أزراراً بصرية متقدمة ومؤثرات حركية فائقة الدقة (CSS Keyframe Animations & Loaders).

تتميز المنصة بتقديم تجربة تفاعلية متكاملة دون الحاجة لأي خادم خلفي (Serverless Client-Side Platform)، وتوفر:
* معاينة حية فورية لكافة المكونات مع عزل برمجي تام.
* محرك بحث وفلترة لحظي فائق السرعة عبر الكلمات المفتاحية والمعرّفات والتصنيفات.
* سلة تجميع بصرية ذكية (Visual Basket Drawer) تتيح تجميع العناصر المفضلة ونسخها مجمعة أو تصديرها كملف HTML مستقل كامل.
* محرك تلوين برمجي مدمج وأوفلاين (Prism.js) يعرض شيفرات HTML و CSS بدقة عالية.

## 2. الفلسفة والحلول المعمارية المطبقة (Architectural Philosophy)

تم بناء **NexusUI** وفق أحدث معايير هندسة البرمجيات للواجهات الأمية، متجاوزة كافة العيوب الشائعة في المعارض التقليدية:

### أ. مبدأ مصدر الحقيقة الوحيد (Single Source of Truth)
* **المشكلة السابقة:** اعتماد أسلوب تجريف الأنماط من المتصفح (CSSOM Scraping) عبر استدعاءات `document.styleSheets` و `getComputedStyle()`، مما كان يسبب انهيار التنسيقات عند تعقيد الـ CSS ويثقل كاهل الذاكرة.
* **الحل المعماري:** استئصال الـ Scraping نهائياً واعتماد ملفات JSON معيارية (`buttons.json` و `animations.json`) كمصدر بيانات موحد وحصري. يحتوي كل كائن على كود الـ HTML الخاص به وقواعد الـ CSS النقية الخاصة به بشكل منفصل ونظيف.

### ب. معمارية الاستجابة الصارمة (Strict Mobile-First Architecture)
* **الأساس الافتراضي:** يبدأ التنسيق في المنصة من شاشات الهواتف الصغيرة (`360px`) كنمط أساسي دون أي ميديا كويري (`No media query for 360px`).
* **خلو تام من استعلامات Max-Width:** تم منع استعلامات الحد الأقصى نهائياً لمنع تضارب الخصائص المتتالية (Cascading Conflicts).
* **التوسع التصاعدي الصارم (Progressive Min-Width Breakpoints):** يعتمد النظام حصرياً على 7 نقاط توقف تصاعدية متسلسلة بدقة:
  1. `@media (min-width: 400px)`: الهواتف العريضة وضبط مرونة الكبسولات.
  2. `@media (min-width: 550px)`: الانتقال لشبكة عرض ثنائية الأعمدة للمحتوى.
  3. `@media (min-width: 750px)`: الأجهزة اللوحية وتوسيع مساحات الترويسة والتوسيط الهندسي.
  4. `@media (min-width: 992px)`: الحواسيب المكتبية، التحول لشبكة الـ Navbar ثلاثية الأعمدة، وإخفاء زر الـ Hamburger وكبسولة السلة السفلية.
  5. `@media (min-width: 1200px)`: الشاشات المكتبية العريضة وتكبير كروت العرض.
  6. `@media (min-width: 1400px)`: الشاشات الضخمة وتوسيع شبكة الـ 4 أعمدة.
  7. `@media (min-width: 1792px)`: الشاشات الفائقة (Ultra-wide) مع تقييد الحاوية المركزية عند `1760px`.

### ج. منظومة الأداء الفائق والتحميل التدريجي (Performance & Virtualization)
* **تقطيع الدفعات (Chunk Rendering):** بدلاً من حقن مئات العناصر دفعة واحدة في شجرة الـ DOM وتجميد المتصفح، يقوم محرك العرض بحقن دفعة أولية تتكون من 30 عنصراً فقط لضمان سرعة تحميل لحظية (First Contentful Paint < 200ms).
* **تجميد الحركات خارج الشاشة (Off-Screen Animation Freezing):** دمج تقنية `content-visibility: auto` مع مراقب التقاطع `IntersectionObserver` لتعليق معالجة الحركات للأجهزة البعيدة عن إطار الرؤية (Viewport)، مما يحافظ على معدل إطارات ثابت عند **60 FPS** واستهلاك ضئيل لمعالج الرسوميات (GPU).

### د. المسرح الافتراضي للمعاينة (Virtual Stage Math)
* **المشكلة:** عند وضع أزرار متباينة الأبعاد ونصوص عريضة داخل كروت سلة التجميع المصغرة (`76px × 52px`)، كانت النصوص تنكسر على سطرين وتتشوه الأزرار.
* **الحل الرياضي:** بناء مسرح افتراضي بأبعاد ثابتة مقيدة هندسياً (`190px × 130px`) يحتوي العنصر بنسبه الطبيعية، ثم تطبيق مصفوفة تحجيم دقيقة بنسبة `scale(0.40)` مع `transform-origin: center center;` داخل حاوية معزولة بـ `overflow: hidden`. ينتج عن ذلك معاينة مصغرة مطابقة للأصل 100% دون أي انكسار أو تشويه.

### هـ. محرك التحميل المستقل (Zero-Server Blob Engine)
* المنصة قادرة على تجميع أي عدد من الأزرار أو الحركات المختارة داخل السلة وتوليد وثيقة HTML5 قياسية كاملة، مدمجة بالأنماط والخطوط والترتيب المناسب، ثم تنزيلها مباشرة إلى حاسوب المستخدم عبر `URL.createObjectURL(new Blob([html], { type: 'text/html' }))` دون الحاجة لخوادم ويب وسيطة.

## 3. شجرة المجلدات ومسؤوليات الملفات (Project Structure)

تم تنظيم المشروع باتباع مبدأ المسؤولية الواحدة (**Single Responsibility Principle**):

```plaintext
yasen/
├── index.html               # الهيكل البنائي الرئيسي والصفحة الموحدة للواجهة
├── README.md                # الوثيقة الفنية الشاملة للمشروع
├── og-preview.webp          # صورة المعاينة الاجتماعية الفاخرة (Social Card 1200x630)
│
├── data/                    # مخزن البيانات ومصدر الحقيقة الوحيد
│   ├── buttons.json         # قاعدة بيانات الأزرار الـ 200 (HTML + CSS + Metadata)
│   └── animations.json      # قاعدة بيانات الحركات واللودرز الـ 200 (HTML + CSS + Metadata)
│
├── css/                     # الطبقة التنسيقية المعيارية المقسمة
│   ├── base.css             # متغيرات التصميم (Tokens)، التنعيم، والخطوط، والـ Reset
│   ├── components.css       # شريط التنقل، السلة العائمة، النوافذ الزجاجية، ونقاط التوقف
│   ├── buttons-core.css     # الأنماط الأساسية الموحدة وقواعد الكروت للأزرار
│   ├── animations-core.css  # قواعد المعاينة الحركية وحاويات العرض للمؤثرات
│   └── prism.css            # سمة تلوين الأكواد المظلمة (Tokyo Night Dark Glass Theme)
│
└── js/                      # الطبقة البرمجية التفاعلية القائمة على وحدات ES6
    ├── app.js               # منسق التطبيق الرئيسي ونقطة البداية (Application Orchestrator)
    ├── renderer.js          # محرك الرسم التدريجي، الفلترة اللحظية، والبحث السريع
    ├── modal.js             # إدارة النوافذ المنبثقة، تلوين الأكواد (Prism)، ونظام الإشعارات
    ├── basket.js            # منطق سلة التجميع، التخزين المحلي، والحسابات البصرية
    ├── generator.js         # محرك توليد وتصدير ملفات الـ HTML الكاملة عبر Blob
    └── prism.js             # محرك تلوين الأكواد البرمجي المحلي والمدمج دون CDN
```

## 4. دليل التشغيل المحلي (How to Run)

> [!IMPORTANT]
> **تنبيه أمان المتصفح (CORS Policy):**
> لا تقم بفتح ملف `index.html` عبر النقر المباشر عليه في المتصفح (`file:///path/index.html`). تفرض المتصفحات الحديثة قيود أمان صارمة تمنع جلب ملفات الـ JSON محلياً عبر تقنية `fetch()`.

### خيارات التشغيل الصحيحة الموصى بها:

1. **عبر ملحق Live Server في VS Code (الخيار الأسهل):**
   * افتح مجلد المشروع في VS Code.
   * انقر بزر الفأرة الأيمن على `index.html` واختر **Open with Live Server**.
   * سيفتح المشروع مباشرة على العنوان: `http://127.0.0.1:5500`.

2. **عبر خادم بايثون السريع (بدون تثبيت برامج):**
   * افتح موجه الأوامر (Terminal / PowerShell) داخل مجلد المشروع ونفّذ:
     ```bash
     python -m http.server 5500
     ```
   * توجّه إلى المتصفح على: `http://localhost:5500`.

3. **عبر Node.js (npx serve):**
   * نفّذ الأمر التالي في مجلد المشروع:
     ```bash
     npx serve .
     ```

## 5. دليل المطور لإضافة عناصر جديدة (Developer Extension Guide)

تعتمد المنصة على معمارية معلنة ذاتية القيادة (**Declarative Architecture**)؛ **لن تحتاج لكتابة أي سطر برمجيات في JavaScript أو HTML** لإضافة مكونات جديدة للمنصة.

### خطوات إضافة زر أو حركة جديدة:

1. افتح ملف `data/buttons.json` (للأزرار) أو `data/animations.json` (للحركات).
2. أضف كائناً جديداً في نهاية المصفوفة مع الالتزام بالبنية المعيارية (JSON Schema):

```json
{
  "id": "btn-neon-pulse-v2",
  "name": "زر نبض النيون المطور",
  "category": "neon",
  "accent": "#48dbfb",
  "html": "<button class=\"btn-neon-pulse\">تفعيل الآن</button>",
  "css": ".btn-neon-pulse {\n  padding: 12px 28px;\n  background: rgba(72, 219, 251, 0.1);\n  border: 1px solid #48dbfb;\n  color: #fff;\n  border-radius: 50px;\n  box-shadow: 0 0 15px rgba(72, 219, 251, 0.4);\n  cursor: pointer;\n  transition: all 0.3s ease;\n}\n.btn-neon-pulse:hover {\n  box-shadow: 0 0 30px rgba(72, 219, 251, 0.8);\n  transform: translateY(-2px);\n}"
}
```

### ماذا يحدث تلقائياً بمجرد حفظ الملف؟
* يقوم `renderer.js` بقراءة العنصر وحساب التصنيف وإدراجه في شريط الفلاتر آلياً.
* يتم توليد بطاقة العرض وحقن التنسيقات في DOM المعزول فوراً.
* يدخل العنصر تلقائياً في منظومة البحث الحي وسلة التجميع.
* يدعم التلوين البرمجي المباشر والتصدير لملفات الـ HTML المستقلة دون أي تعديل يدوي.

## 6. الهوية البصرية ومنظومة الخطوط (Design Tokens & Typography)

تم تطبيق نظام بصري عربي متقدم يعتمد على فلسفة الزجاج المصقول الداكن (Dark Glassmorphism) والطباعة المزدوجة:

* **خط Cairo (`--font-primary`):** الخط الأساسي الرصين للشعار، عناوين الـ Hero، عناوين البطاقات، النوافذ، والأزرار التفاعلية الرئيسية.
* **خط Tajawal (`--font-secondary`):** خط القراءة الانسيابي المخصص للفقرات الشارحة، الشارات، التصنيفات، حقول البحث، ورسائل التنبيه.
* **خط Monospace (`--font-code`):** عزل تام لمناطق استعراض الأكواد البرمجية (`pre`, `code`) بخطي `JetBrains Mono` / `Fira Code` مع فرض صارم لاتجاه اليسار إلى اليمين (`direction: ltr !important`).
* **شريط التنقل المتناظر (Symmetrical Header):** تصميم زجاجي نقي مع حشوة جانبية فسيحة (`20px`) تفصل العناصر عن الحواف، مع كبسولة سلة سفلية عائمة حديثة على الهواتف.
* **نظام الإشعارات الرأسي (Heads-up Notification):** انزلاق الإشعارات من قمة الشاشة لتبقى السلة السفلية حرة وخالية من أي حجب بصري.
* **بطاقة المطور الزجاجية (#developerModal):** تصميم مخصص بطراز زجاج الغوريلا (Gorilla Glass) مع تفاعل نيون متقدم وعزل تام لزر الإغلاق وتوافق 100% مع شاشات 360px.
